# ETL com PostgreSQL + Pandas + SQLAlchemy

Projeto básico para manipulação de dados usando Python, Pandas e PostgreSQL.

## Como usar

1. Crie um arquivo `.env` com suas credenciais de acesso ao banco de dados:
```.env
DB_USER=postgres 
DB_PASSWORD=sua_senha_aqui 
DB_HOST=localhost 
DB_PORT=5432 
DB_NAME=etl_s 
```

2. Instale as dependências:

```bash
pip install -r requirements.txt
```
